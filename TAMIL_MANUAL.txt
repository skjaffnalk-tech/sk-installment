NEW SK PHONE SHOP – தவணை மேலாண்மை மென்பொருள் – பயனர் கையேடு
==========================================================

1. நிறுவல் (Setup)
------------------
1) ZIP கோப்பை Extract செய்யவும் (Right click → Extract All).
2) INSTALL.bat ஐ Double click செய்யவும்.
3) Desktop-இல் "SK Installment" shortcut உருவாகும். எப்போதும் அதையே திறக்கவும்.
   (வேறு இடத்திலிருந்து HTML ஐ திறந்தால் தரவு வேறாகத் தெரியும்!)
4) Chrome அல்லது Edge பயன்படுத்தவும்.

முதல் முறை திறக்கும்போது Admin கடவுச்சொல் உருவாக்கச் சொல்லும். அதை மறக்காதீர்கள்.
(கடவுச்சொல் மறந்தால் மீட்க முடியாது – JSON காப்புப்பிரதி மட்டுமே வழி.)

2. தரவுத்தளம் (Database)
------------------------
தனியாக நிறுவ எதுவும் இல்லை. தரவு உங்கள் கணினியின் Chrome/Edge IndexedDB-இல் சேமிக்கப்படும்.
Refresh செய்தாலும் தரவு இழக்காது.
எச்சரிக்கை: Browser-இன் "Clear browsing data → Cookies and site data" செய்தால் தரவு அழியும்.
அதனால் தினமும் காப்புப்பிரதி எடுக்கவும்.

3. பயன்பாடு
-----------
* வாடிக்கையாளர்: "+ புதிய" → விவரம் நிரப்பு → சேமி. பின் "திற" → "+ தொலைபேசி".
* தொலைபேசி: மாடல், IMEI (14-16 இலக்கம்), விலை, முன்பணம், மாதங்கள் → "மாதத்தவணை கணக்கிடு".
  ஒரு வாடிக்கையாளருக்கு எத்தனை தொலைபேசிகளும் சேர்க்கலாம்.
* கட்டணம்: தொலைபேசி வரிசையில் "கட்டணம்" → தொகை, முறை → பதிவு செய் → ரசீது (A4 / Thermal).
  அட்டை எண் / CVV ஒருபோதும் பதிவு செய்யாதீர்கள்.
* திருத்தம் (Admin மட்டும்): "வரலாறு" → "திருத்து" → காரணம் எழுதவும். பழைய மதிப்பு தணிக்கையில் இருக்கும்.
* நிலை: Paid = முழுவதும் செலுத்தியது; Overdue = மாத தேதிகள் கடந்தும் செலுத்தாதது;
  Partial = பகுதி செலுத்தி, தாமதம் இல்லை; Unpaid = இதுவரை செலுத்தவில்லை.
* பங்குகள்: Admin = அனைத்தும். Cashier = வாடிக்கையாளர் பதிவு, தொலைபேசி சேர்ப்பு, கட்டணம் பதிவு.

4. 86 வாடிக்கையாளர்களை இறக்குமதி செய்தல்
-----------------------------------------
1) "இறக்குமதி/ஏற்றுமதி" → "வெற்று டெம்ப்ளேட்" பதிவிறக்கவும்.
2) Excel-இல் திறந்து, ஒரு வரிசைக்கு ஒரு தொலைபேசி நிரப்பவும்.
   ஒரே வாடிக்கையாளருக்கு பல தொலைபேசி = அதே பெயர்/கைப்பேசி/NIC உடன் பல வரிசைகள்.
   திகதி வடிவம்: YYYY-MM-DD (எ.கா. 2026-03-15).
3) File → Save As → "CSV UTF-8" ஆக சேமிக்கவும் (தமிழ் எழுத்துக்கு முக்கியம்).
4) மென்பொருளில் கோப்பைத் தேர்ந்தெடுத்து "சரிபார்" அழுத்தவும். பிழைகள் பட்டியலிடப்படும்;
   உரைப்பெட்டியிலேயே திருத்தி மீண்டும் "சரிபார்". நகல் IMEI தடுக்கப்படும்.
5) "இறக்கு" → உறுதிப்படுத்தவும். ஏற்கனவே உள்ளவை மாற்றப்படாது.
முதலில் ஒரு வரிசையுடன் சோதித்துப் பாருங்கள்.

5. காப்புப்பிரதி & மீட்பு
-------------------------
* காப்புப்பிரதி: "Backup" → "JSON காப்புப்பிரதி பதிவிறக்கு". கோப்பை USB / Google Drive-இல் வைக்கவும்.
  தினமும் இரவு கடை மூடும்போது எடுக்கவும் (முகப்பு 7 நாட்களுக்குப் பின் எச்சரிக்கும்).
* மீட்பு: "Backup" → மீட்டெடு → JSON தேர்வு. கோப்பு சரிபார்க்கப்படும்; உறுதிப்படுத்தினால்
  மட்டுமே மாற்றும்; மாற்றும் முன் தற்போதைய தரவு தானாக பதிவிறக்கப்படும்.
* புதிய கணினியில்: INSTALL.bat → முதல் முறை கடவுச்சொல் உருவாக்கு → Backup → மீட்டெடு.

6. அறிக்கைகள்
-------------
"Reports" → வகை, திகதிகள் தேர்வு → "CSV" (Excel) அல்லது "PDF / அச்சு" (Print window-இல்
Destination = Save as PDF).

7. சோதனை வழிமுறை (Testing)
---------------------------
1) Admin உருவாக்கு → உள்நுழை → Users-இல் ஒரு Cashier சேர்.
2) சோதனை வாடிக்கையாளர் உருவாக்கு (பின் நீக்கலாம்).
3) தொலைபேசி: விலை 100000, முன்பணம் 20000, 8 மாதம் → மாதத்தவணை 10000. மீதி 80000 என்பதைச் சரிபார்.
4) 10000 கட்டணம் → மீதி 70000. ரசீதில் முந்தைய மீதி 80000, மீதி 70000 என இருக்க வேண்டும்.
5) அதே தொகை/திகதி மீண்டும் பதிவிடு → நகல் எச்சரிக்கை வர வேண்டும்.
6) மீதியை விட அதிகம் உள்ளிடு → தடுக்க வேண்டும்.
7) Admin: கட்டணத்தைத் திருத்து → Audit-இல் காரணம் தெரிய வேண்டும். Cashier-ஆக உள்நுழைந்தால் திருத்து பொத்தான் இருக்கக்கூடாது.
8) அதே IMEI மீண்டும் சேர்த்தால் நிராகரிக்க வேண்டும்.
9) Browser-ஐ Refresh / மூடித் திற → தரவு இருக்க வேண்டும்.
10) Backup எடுத்து, Restore செய்து எண்ணிக்கைகள் ஒன்றாக உள்ளதா எனப் பார்.
11) A4 மற்றும் Thermal ரசீது அச்சுப் பார்வையைச் சரிபார்.
உண்மையான தரவு உள்ளிடும் முன் சோதனைப் பதிவுகளை நீக்கவும் (அல்லது புதிய கணினியில் சோதிக்கவும்).
